# 🛒 Proyecto Cesta de Compra

## 📌 Sobre

Este proyecto fue desarrollado por **Isaias Daniel** con el objetivo de crear una aplicación sencilla e intuitiva para simular una **lista de compras**, permitiendo agregar, visualizar y gestionar productos de forma dinámica usando tecnologías web.

## ✨ Funcionalidades

- ➕ Agregar productos a la lista.
- 🗑️ Eliminar productos.
- ✅ Marcar productos como comprados.
- 📱 Diseño adaptable para uso móvil y escritorio.
