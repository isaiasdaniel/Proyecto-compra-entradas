# 🛒 Proyecto Cesta de Compra

## 📌 Acerca del proyecto
Este proyecto fue desarrollado por **Isaias Daniel** con el objetivo de crear una aplicación **sencilla e intuitiva** para simular una **lista de compras**, permitiendo agregar, visualizar y gestionar productos de forma dinámica mediante tecnologías web.

## ✨ Funcionalidades
- ➕ Agregar productos a la lista.  
- 🗑️ Eliminar productos.  
- ✅ Marcar productos como comprados.  
- 📱 Diseño adaptable para **móvil y escritorio**.  

---

## 📖 Regla de negocio
- El usuario puede **añadir productos** con nombre y cantidad a la lista.  
- Los productos pueden ser **eliminados** en cualquier momento.  
- Cada producto puede ser marcado como **“comprado”** para un mejor control de la compra.  
- La lista se actualiza dinámicamente en el navegador, sin necesidad de recargar la página.  
- La aplicación está pensada como **base para evolución futura** (integración con base de datos, login o carrito de compra real).
